     6→## 1. PROJECT OVERVIEW
     7→
     8→**What you're building:**
     9→An agentic AI system that autonomously reconciles a merchant's internal order database against Razorpay settlement reports and bank statements. It resolves multi-leg settlements (split payments, partial refunds, blended fees), auto-matches 90% of records, and generates an honest exception list with forensic audit trails for the remaining 10%.
    10→
    11→**Core thesis:** Verification capacity > Generation speed. The AI never guesses financial data. It either proves a match mathematically or honestly admits it cannot resolve.
    12→
    13→**What makes this win:**
    14→- Handles multi-leg settlement graphs (not just 1-to-1 matching)
    15→- Uses AI for text extraction and code generation, NEVER for arithmetic
    16→- Produces an honest exception list with forensic dossiers
    17→- Idempotent, auditable, bounded execution
    18→- Closes the finance-ops loop (doesn't just report, but prepares resolution)

   202→### 4.6 Specific Data Quirks to Include
   203→
   204→**Quirk 1: MDR Fee Deduction**
   205→- Internal order: ₹10,000, payment_method: "credit_card"
   206→- Razorpay settlement: amount=10000, fee_amount=200 (2% MDR)
   207→- Bank statement: narration shows ₹9,800 credit
   208→- Agent must identify the ₹200 gap as MDR
   209→
   210→**Quirk 2: TDS Deduction**
   211→- Internal order: ₹10,000
   212→- Razorpay settlement: amount=10000, fee_amount=0
   213→- Bank statement: ₹9,900 credit
   214→- Agent must identify ₹100 as 1% TDS
   215→
   216→**Quirk 3: Multi-Leg Settlement**
   217→- Bank statement: Single credit of ₹42,500
   218→- Internal orders: ORD-0010 (₹15,000), ORD-0011 (₹12,000), ORD-0012 (₹16,000)
   219→- Total orders: ₹43,000, minus 2% blended MDR (₹860) = ₹42,140... wait, let me recalculate.
   220→- Actually: Orders total ₹43,000. MDR on each: ₹15,000 × 2% = ₹300, ₹12,000 × 2% = ₹240, ₹16,000 × 2% = ₹320. Total MDR = ₹860. Net = ₹42,140.
   221→- Bank credit: ₹42,140 with narration "RZRPAY SETTLEMENT BATCH 20250829"
   222→- Agent must figure out which 3 orders sum to this amount after fees
   223→
   224→**Quirk 4: Partial Refund**
   225→- Internal order: ₹7,500, refund_amount: ₹2,000
   226→- Razorpay settlement: amount=7500, refund_amount=2000, fee_amount=150
   227→- Bank statement: ₹5,350 credit (7500 - 2000 - 150 = 5350)
   228→- Agent must reconstruct: Order - Refund - Fee = Bank Credit
   229→
   230→**Quirk 5: UPI Reference Mismatch**
   231→- Internal order: ORD-2025-0040, amount ₹3,000
   232→- Razorpay settlement: UTR = "UTR9834726140"
   233→- Bank statement: reference = "UPI/329084716201" (different format)
   234→- Agent must match via Order ID extraction from narration, not UTR
   235→
   236→**Quirk 6: Malformed Narration**
   237→- Bank narration: "RAZORPAY////ORD-2025-00//ERR" (garbled)
   238→- Amount: ₹6,000
   239→- Agent should flag this as low-confidence extraction
   240→
   241→**Quirk 7: Honest Exceptions**
   242→- Record with no matching settlement at all
   243→- Record with duplicate bank credit
   244→- Record where amount differs by an unexplainable margin (e.g., ₹10,000 order, ₹4,000 bank credit, no refund record)
   245→- Record with a future date (settlement date is after the batch window)
   246→- Record with currency mismatch (USD instead of INR)

   252→### 5.1 Pipeline Orchestrator (`src/pipeline.py`)
   253→
   254→```python
   255→class ReconPipeline:
   256→    """
   257→    Main orchestrator that runs all 4 stages sequentially.
   258→    Must be idempotent: running the same input twice produces identical output.
   259→    """
   260→    
   261→    def run(self, internal_orders, razorpay_settlements, bank_statement) -> ReconReport:
   262→        """
   263→        Returns a ReconReport containing:
   264→        - matched_records: list of MatchedRecord
   265→        - honest_exceptions: list of ExceptionRecord
   266→        - processing_errors: list of ProcessingError
   267→        - metrics: PipelineMetrics
   268→        - audit_trail: list of AuditEntry
   269→        """
   270→        
   271→        audit = AuditTrail()
   272→        
   273→        # Stage 1: Deterministic Hard Match
   274→        stage1_result = Stage1HardMatch().run(internal_orders, razorpay_settlements, bank_statement)
   275→        audit.log("Stage 1 complete", stage1_result.metrics)
   276→        
   277→        # Remove matched records from remaining pool
   278→        remaining_orders = stage1_result.unmatched_orders
   279→        remaining_bank_credits = stage1_result.unmatched_bank_credits
   280→        
   281→        # Stage 2: AI Semantic Normalization
   282→        stage2_result = Stage2Normalizer().run(remaining_orders, remaining_bank_credits)
   283→        audit.log("Stage 2 complete", stage2_result.metrics)
   284→        
   285→        # Stage 3: Multi-Leg Graph Resolution
   286→        stage3_result = Stage3GraphResolver().run(stage2_result.unmatched_orders, stage2_result.unmatched_bank_credits)
   287→        audit.log("Stage 3 complete", stage3_result.metrics)
   288→        
   289→        # Stage 4: Honest Exception Orchestrator
   290→        stage4_result = Stage4ExceptionOrchestrator().run(stage3_result.unresolved_records, audit)
   291→        audit.log("Stage 4 complete", stage4_result.metrics)
   292→        
   293→        return ReconReport(
   294→            matched_records=stage1_result.matched + stage2_result.matched + stage3_result.matched,
   295→            honest_exceptions=stage4_result.exceptions,
   296→            processing_errors=stage4_result.processing_errors,
   297→            metrics=self._calculate_metrics(stage1_result, stage2_result, stage3_result, stage4_result),
   298→            audit_trail=audit
   299→        )
   300→```

   302→### 5.2 Stage 1: Deterministic Hard Match (`src/stage1_hard_match.py`)
   303→
   304→**Logic:** Pure Python, no AI. Match on exact `order_id` + exact `amount` + exact `utr`.
   305→
   306→```python
   307→class Stage1HardMatch:
   308→    """
   309→    Deterministic 1-to-1 matching. No AI involved.
   310→    This is the guardrail layer.
   311→    """
   312→    
   313→    def run(self, orders, settlements, bank_credits) -> Stage1Result:
   314→        matched = []
   315→        unmatched_orders = []
   316→        unmatched_bank = []
   317→        
   318→        # Build lookup indices
   319→        settlement_by_order = {s.order_id: s for s in settlements}
   320→        bank_by_utr = {b.reference_number: b for b in bank_credits}
   321→        
   322→        for order in orders:
   323→            settlement = settlement_by_order.get(order.order_id)
   324→            if settlement is None:
   325→                unmatched_orders.append(order)
   326→                continue
   327→            
   328→            bank_credit = bank_by_utr.get(settlement.utr)
   329→            if bank_credit is None:
   330→                unmatched_orders.append(order)
   331→                continue
   332→            
   333→            # Exact match: order amount == settlement amount == bank credit amount
   334→            if (order.amount == settlement.amount and 
   335→                settlement.amount == bank_credit.amount):
   336→                matched.append(MatchedRecord(
   337→                    order=order,
   338→                    settlement=settlement,
   339→                    bank_credit=bank_credit,
   340→                    match_type="DETERMINISTIC_1_TO_1",
   341→                    confidence=1.0
   342→                ))
   343→            else:
   344→                unmatched_orders.append(order)
   345→                unmatched_bank.append(bank_credit)
   346→        
   347→        return Stage1Result(matched, unmatched_orders, unmatched_bank)
   348→```

   350→### 5.3 Stage 2: AI Semantic Normalizer (`src/stage2_normalizer.py`)
   351→
   352→**Logic:** Use LLM to extract structured fields from messy bank narrations. LLM returns confidence score.
   353→
   354→**LLM Prompt Template:**
   355→
   356→```python
   357→NORMALIZATION_PROMPT = """
   358→You are a bank statement parser for Razorpay settlements. Extract structured fields from the following bank narration.
   359→
   360→Bank Narration: "{narration}"
   361→
   362→Return ONLY a JSON object with these fields:
   363→- order_id: The Razorpay order ID if present (e.g., "ORD-2025-0001")
   364→- merchant_name: The merchant name if present
   365→- reference_number: Any UTR or reference number if present
   366→- settlement_batch: The settlement batch identifier if present
   367→- confidence: "high" if you are very certain, "medium" if somewhat certain, "low" if uncertain
   368→
   369→Rules:
   370→- Do NOT guess. If a field is not clearly present, set it to null.
   371→- Do NOT perform any calculations.
   372→- Do NOT infer amounts.
   373→- Return ONLY valid JSON. No explanations.
   374→"""
   375→```
   376→
   377→**Confidence Gate Logic:**
   378→
   379→```python
   380→class Stage2Normalizer:
   381→    def run(self, orders, bank_credits) -> Stage2Result:
   382→        matched = []
   383→        unmatched_orders = list(orders)
   384→        unmatched_bank = []
   385→        
   386→        for bank_credit in bank_credits:
   387→            extraction = self.llm_client.extract_narration(bank_credit.narration)
   388→            
   389→            if extraction.confidence == "high":
   390→                # Try to match using extracted order_id
   391→                matching_order = self._find_order_by_id(extraction.order_id, unmatched_orders)
   392→                if matching_order and matching_order.amount == bank_credit.amount:
   393→                    matched.append(MatchedRecord(
   394→                        order=matching_order,
   395→                        bank_credit=bank_credit,
   396→                        match_type="AI_SEMANTIC_NORMALIZATION",
   397→                        confidence=0.95,
   398→                        extraction=extraction
   399→                    ))
   400→                    unmatched_orders.remove(matching_order)
   401→                else:
   402→                    unmatched_bank.append(bank_credit)
   403→            
   404→            elif extraction.confidence == "medium":
   405→                # Flag for human verification of extracted fields
   406→                unmatched_bank.append(BankCreditWithFlag(
   407→                    bank_credit,
   408→                    flag="MEDIUM_CONFIDENCE_EXTRACTION",
   409→                    extracted_fields=extraction
   410→                ))
   411→            
   412→            else:  # low confidence
   413→                unmatched_bank.append(BankCreditWithFlag(
   414→                    bank_credit,
   415→                    flag="LOW_CONFIDENCE_EXTRACTION",
   416→                    extracted_fields=extraction
   417→                ))
   418→        
   419→        return Stage2Result(matched, unmatched_orders, unmatched_bank)
   420→```

   422→### 5.4 Stage 3: Multi-Leg Graph Resolver (`src/stage3_graph_resolver.py`)
   423→
   424→**Logic:** For lump-sum bank credits that don't match any single order, use LLM to generate Python code that finds the combination of orders + refunds + fees that equals the bank credit.
   425→
   426→**LLM Prompt Template:**
   427→
   428→```python
   429→GRAPH_RESOLVER_PROMPT = """
   430→You are a financial reconciliation assistant. You need to find which combination of internal orders, minus refunds and fees, equals a bank credit.
   431→
   432→Bank Credit Amount: ₹{bank_credit_amount}
   433→Bank Narration: "{narration}"
   434→
   435→Available Internal Orders:
   436→{orders_json}
   437→
   438→Fee Matrix:
   439→- UPI: 0% MDR
   440→- Net Banking: 1% MDR  
   441→- Credit Card: 2% MDR
   442→- Debit Card: 1.5% MDR
   443→- TDS: 1% (applied on settlement amount for certain merchant categories)
   444→
   445→Rules:
   446→1. Write a Python function called `find_match(orders, bank_credit_amount)` that:
   447→   - Tries all combinations of 1 to 5 orders
   448→   - For each combination, calculates the net amount after applying the correct MDR fee based on payment_method
   449→   - Subtracts any refund amounts
   450→   - Checks if the net amount equals bank_credit_amount within a tolerance of ₹0.01
   451→   - Returns the matching combination and the fee breakdown, or None if no match found
   452→2. The function must use itertools.combinations
   453→3. The function must have a maximum execution time of 5 seconds (use signal.alarm if possible)
   454→4. Do NOT use any external libraries beyond itertools, math
   455→5. Do NOT make assumptions about data not provided
   456→6. Return ONLY the Python code. No explanations.
   457→
   458→Write the function now:
   459→"""
   460→```
   461→
   462→**Code Sandbox (`ai/code_sandbox.py`):**
   463→
   464→```python
   465→import subprocess
   466→import tempfile
   467→import os
   468→import signal
   469→
   470→class CodeSandbox:
   471→    """
   472→    Safely executes LLM-generated Python code.
   473→    If the code doesn't match exactly, returns None.
   474→    """
   475→    
   476→    TIMEOUT_SECONDS = 5
   477→    
   478→    def execute(self, code: str, orders: list, bank_credit_amount: float) -> dict:
   479→        # Create a temporary Python file
   480→        with tempfile.NamedTemporaryFile(mode='w', suffix='.py', delete=False) as f:
   481→            # Add the generated function + test invocation
   482→            test_code = f"""
   483→{code}
   484→
   485→# Test invocation
   486→result = find_match({orders}, {bank_credit_amount})
   487→print(result)
   488→"""
   489→            f.write(test_code)
   490→            temp_path = f.name
   491→        
   492→        try:
   493→            # Execute with timeout
   494→            result = subprocess.run(
   495→                ['python', temp_path],
   496→                capture_output=True,
   497→                text=True,
   498→                timeout=self.TIMEOUT_SECONDS
   499→            )
   500→            
   501→            if result.returncode == 0 and result.stdout.strip() != "None":
   502→                import json
   503→                return json.loads(result.stdout.strip())
   504→            else:
   505→                return None
   506→        
   507→        except subprocess.TimeoutExpired:
   508→            return {"error": "COMBINATORIAL_TIMEOUT"}
   509→        
   510→        finally:
   511→            os.unlink(temp_path)
   512→```

   514→### 5.5 Stage 4: Honest Exception Orchestrator (`src/stage4_exception.py`)
   515→
   516→**Logic:** For all unresolved records, generate a forensic dossier documenting every step taken.
   517→
   518→```python
   519→class Stage4ExceptionOrchestrator:
   520→    def run(self, unresolved_records, audit_trail) -> Stage4Result:
   521→        exceptions = []
   522→        processing_errors = []
   523→        
   524→        for record in unresolved_records:
   525→            try:
   526→                dossier = self._generate_forensic_dossier(record, audit_trail)
   527→                
   528→                # Generate dispute payload
   529→                dispute_payload = self._generate_dispute_payload(record, dossier)
   530→                
   531→                # Update ledger status
   532→                self._update_ledger_status(record.order_id, "ESCALATED")
   533→                
   534→                # Push webhook (simulate)
   535→                self._push_webhook(dispute_payload)
   536→                
   537→                exceptions.append(ExceptionRecord(
   538→                    record=record,
   539→                    dossier=dossier,
   540→                    dispute_payload=dispute_payload,
   541→                    status="ESCALATED"
   542→                ))
   543→            
   544→            except Exception as e:

   546→                    record_id=record.order_id,

   574→### 5.6 Fee Calculator (`src/fee_calculator.py`)
   575→
   576→```python
   577→class FeeCalculator:
   578→    """
   579→    Deterministic fee calculation engine.
   580→    This is the source of truth for all fee computations.
   581→    """
   582→    
   583→    FEE_MATRIX = {
   584→        "upi": 0.00,
   585→        "netbanking": 0.01,
   586→        "credit_card": 0.02,
   587→        "debit_card": 0.015,
   588→        "wallet": 0.02,
   589→    }
   590→    
   591→    TDS_RATE = 0.01  # 1% TDS
   592→    
   593→    def calculate_mdr(self, amount: float, payment_method: str) -> float:
   594→        rate = self.FEE_MATRIX.get(payment_method, 0.02)  # Default to 2%
   595→        return round(amount * rate, 2)
   596→    
   597→    def calculate_tds(self, amount: float) -> float:
   598→        return round(amount * self.TDS_RATE, 2)
   599→    
   600→    def calculate_net_settlement(self, order) -> float:
   601→        mdr = self.calculate_mdr(order.amount, order.payment_method)
   602→        refund = order.refund_amount or 0.00
   603→        net = order.amount - mdr - refund
   604→        
   605→        if order.route_split:
   606→            # For Route splits, platform fee is already included in route_split
   607→            net = order.route_split.vendor_amount - refund
   608→        
   609→        return round(net, 2)
   610→```

   637→            "confidence": confidence,
   638→        })
   639→    
   640→    def log_exception(self, record_id: str, reason: str):
   641→        self.log("EXCEPTION_FLAGGED", {
   642→            "record_id": record_id,
   643→            "reason": reason,
   644→        })
   645→    
   646→    def to_json(self) -> str:
   647→        return json.dumps(self.entries, indent=2)
   648→    
   649→    def to_dataframe(self):

   651→        return pl.DataFrame(self.entries)
