# ClearCut: The Self-Resolving Finance Controller
## Complete Build Specification Document

---

## 1. PROJECT OVERVIEW

**What you're building:**
An agentic AI system that autonomously reconciles a merchant's internal order database against Razorpay settlement reports and bank statements. It resolves multi-leg settlements (split payments, partial refunds, blended fees), auto-matches 90% of records, and generates an honest exception list with forensic audit trails for the remaining 10%.

**Core thesis:** Verification capacity > Generation speed. The AI never guesses financial data. It either proves a match mathematically or honestly admits it cannot resolve.

**What makes this win:**
- Handles multi-leg settlement graphs (not just 1-to-1 matching)
- Uses AI for text extraction and code generation, NEVER for arithmetic
- Produces an honest exception list with forensic dossiers
- Idempotent, auditable, bounded execution
- Closes the finance-ops loop (doesn't just report, but prepares resolution)

### 4.6 Specific Data Quirks to Include

**Quirk 1: MDR Fee Deduction**
- Internal order: ₹10,000, payment_method: "credit_card"
- Razorpay settlement: amount=10000, fee_amount=200 (2% MDR)
- Bank statement: narration shows ₹9,800 credit
- Agent must identify the ₹200 gap as MDR

**Quirk 2: TDS Deduction**
- Internal order: ₹10,000
- Razorpay settlement: amount=10000, fee_amount=0
- Bank statement: ₹9,900 credit
- Agent must identify ₹100 as 1% TDS

**Quirk 3: Multi-Leg Settlement**
- Bank statement: Single credit of ₹42,500
- Internal orders: ORD-0010 (₹15,000), ORD-0011 (₹12,000), ORD-0012 (₹16,000)
- Total orders: ₹43,000, minus 2% blended MDR (₹860) = ₹42,140... wait, let me recalculate.
- Actually: Orders total ₹43,000. MDR on each: ₹15,000 × 2% = ₹300, ₹12,000 × 2% = ₹240, ₹16,000 × 2% = ₹320. Total MDR = ₹860. Net = ₹42,140.
- Bank credit: ₹42,140 with narration "RZRPAY SETTLEMENT BATCH 20250829"
- Agent must figure out which 3 orders sum to this amount after fees

**Quirk 4: Partial Refund**
- Internal order: ₹7,500, refund_amount: ₹2,000
- Razorpay settlement: amount=7500, refund_amount=2000, fee_amount=150
- Bank statement: ₹5,350 credit (7500 - 2000 - 150 = 5350)
- Agent must reconstruct: Order - Refund - Fee = Bank Credit

**Quirk 5: UPI Reference Mismatch**
- Internal order: ORD-2025-0040, amount ₹3,000
- Razorpay settlement: UTR = "UTR9834726140"
- Bank statement: reference = "UPI/329084716201" (different format)
- Agent must match via Order ID extraction from narration, not UTR

**Quirk 6: Malformed Narration**
- Bank narration: "RAZORPAY////ORD-2025-00//ERR" (garbled)
- Amount: ₹6,000
- Agent should flag this as low-confidence extraction

**Quirk 7: Honest Exceptions**
- Record with no matching settlement at all
- Record with duplicate bank credit
- Record where amount differs by an unexplainable margin (e.g., ₹10,000 order, ₹4,000 bank credit, no refund record)
- Record with a future date (settlement date is after the batch window)
- Record with currency mismatch (USD instead of INR)

## 5. CORE PIPELINE SPECIFICATION

### 5.1 Pipeline Orchestrator (`src/pipeline.py`)

```python
class ReconPipeline:
    """
    Main orchestrator that runs all 4 stages sequentially.
    Must be idempotent: running the same input twice produces identical output.
    """
    
    def run(self, internal_orders, razorpay_settlements, bank_statement) -> ReconReport:
        """
        Returns a ReconReport containing:
        - matched_records: list of MatchedRecord
        - honest_exceptions: list of ExceptionRecord
        - processing_errors: list of ProcessingError
        - metrics: PipelineMetrics
        - audit_trail: list of AuditEntry
        """
        
        audit = AuditTrail()
        
        # Stage 1: Deterministic Hard Match
        stage1_result = Stage1HardMatch().run(internal_orders, razorpay_settlements, bank_statement)
        audit.log("Stage 1 complete", stage1_result.metrics)
        
        # Remove matched records from remaining pool
        remaining_orders = stage1_result.unmatched_orders
        remaining_bank_credits = stage1_result.unmatched_bank_credits
        
        # Stage 2: AI Semantic Normalization
        stage2_result = Stage2Normalizer().run(remaining_orders, remaining_bank_credits)
        audit.log("Stage 2 complete", stage2_result.metrics)
        
        # Stage 3: Multi-Leg Graph Resolution
        stage3_result = Stage3GraphResolver().run(stage2_result.unmatched_orders, stage2_result.unmatched_bank_credits)
        audit.log("Stage 3 complete", stage3_result.metrics)
        
        # Stage 4: Honest Exception Orchestrator
        stage4_result = Stage4ExceptionOrchestrator().run(stage3_result.unresolved_records, audit)
        audit.log("Stage 4 complete", stage4_result.metrics)
        
        return ReconReport(
            matched_records=stage1_result.matched + stage2_result.matched + stage3_result.matched,
            honest_exceptions=stage4_result.exceptions,
            processing_errors=stage4_result.processing_errors,
            metrics=self._calculate_metrics(stage1_result, stage2_result, stage3_result, stage4_result),
            audit_trail=audit
        )
```

### 5.2 Stage 1: Deterministic Hard Match (`src/stage1_hard_match.py`)

**Logic:** Pure Python, no AI. Match on exact `order_id` + exact `amount` + exact `utr`.

```python
class Stage1HardMatch:
    """
    Deterministic 1-to-1 matching. No AI involved.
    This is the guardrail layer.
    """
    
    def run(self, orders, settlements, bank_credits) -> Stage1Result:
        matched = []
        unmatched_orders = []
        unmatched_bank = []
        
        # Build lookup indices
        settlement_by_order = {s.order_id: s for s in settlements}
        bank_by_utr = {b.reference_number: b for b in bank_credits}
        
        for order in orders:
            settlement = settlement_by_order.get(order.order_id)
            if settlement is None:
                unmatched_orders.append(order)
                continue
            
            bank_credit = bank_by_utr.get(settlement.utr)
            if bank_credit is None:
                unmatched_orders.append(order)
                continue
            
            # Exact match: order amount == settlement amount == bank credit amount
            if (order.amount == settlement.amount and 
                settlement.amount == bank_credit.amount):
                matched.append(MatchedRecord(
                    order=order,
                    settlement=settlement,
                    bank_credit=bank_credit,
                    match_type="DETERMINISTIC_1_TO_1",
                    confidence=1.0
                ))
            else:
                unmatched_orders.append(order)
                unmatched_bank.append(bank_credit)
        
        return Stage1Result(matched, unmatched_orders, unmatched_bank)
```

### 5.3 Stage 2: AI Semantic Normalizer (`src/stage2_normalizer.py`)

**Logic:** Use LLM to extract structured fields from messy bank narrations. LLM returns confidence score.

**LLM Prompt Template:**

```python
NORMALIZATION_PROMPT = """
You are a bank statement parser for Razorpay settlements. Extract structured fields from the following bank narration.

Bank Narration: "{narration}"

Return ONLY a JSON object with these fields:
- order_id: The Razorpay order ID if present (e.g., "ORD-2025-0001")
- merchant_name: The merchant name if present
- reference_number: Any UTR or reference number if present
- settlement_batch: The settlement batch identifier if present
- confidence: "high" if you are very certain, "medium" if somewhat certain, "low" if uncertain

Rules:
- Do NOT guess. If a field is not clearly present, set it to null.
- Do NOT perform any calculations.
- Do NOT infer amounts.
- Return ONLY valid JSON. No explanations.
"""
```

**Confidence Gate Logic:**

```python
class Stage2Normalizer:
    def run(self, orders, bank_credits) -> Stage2Result:
        matched = []
        unmatched_orders = list(orders)
        unmatched_bank = []
        
        for bank_credit in bank_credits:
            extraction = self.llm_client.extract_narration(bank_credit.narration)
            
            if extraction.confidence == "high":
                # Try to match using extracted order_id
                matching_order = self._find_order_by_id(extraction.order_id, unmatched_orders)
                if matching_order and matching_order.amount == bank_credit.amount:
                    matched.append(MatchedRecord(
                        order=matching_order,
                        bank_credit=bank_credit,
                        match_type="AI_SEMANTIC_NORMALIZATION",
                        confidence=0.95,
                        extraction=extraction
                    ))
                    unmatched_orders.remove(matching_order)
                else:
                    unmatched_bank.append(bank_credit)
            
            elif extraction.confidence == "medium":
                # Flag for human verification of extracted fields
                unmatched_bank.append(BankCreditWithFlag(
                    bank_credit,
                    flag="MEDIUM_CONFIDENCE_EXTRACTION",
                    extracted_fields=extraction
                ))
            
            else:  # low confidence
                unmatched_bank.append(BankCreditWithFlag(
                    bank_credit,
                    flag="LOW_CONFIDENCE_EXTRACTION",
                    extracted_fields=extraction
                ))
        
        return Stage2Result(matched, unmatched_orders, unmatched_bank)
```

### 5.4 Stage 3: Multi-Leg Graph Resolver (`src/stage3_graph_resolver.py`)

**Logic:** For lump-sum bank credits that don't match any single order, use LLM to generate Python code that finds the combination of orders + refunds + fees that equals the bank credit.

**LLM Prompt Template:**

```python
GRAPH_RESOLVER_PROMPT = """

Bank Credit Amount: ₹{bank_credit_amount}
Bank Narration: "{narration}"

Available Internal Orders:
{orders_json}

Fee Matrix:
- UPI: 0% MDR
- Net Banking: 1% MDR  
- Credit Card: 2% MDR
- Debit Card: 1.5% MDR
- TDS: 1% (applied on settlement amount for certain merchant categories)

   - Tries all combinations of 1 to 5 orders

   - Subtracts any refund amounts
   - Checks if the net amount equals bank_credit_amount within a tolerance of ₹0.01
   - Returns the matching combination and the fee breakdown, or None if no match found

3. The function must have a maximum execution time of 5 seconds (use signal.alarm if possible)
```

**Code Sandbox (`ai/code_sandbox.py`):**

```python
import subprocess
import tempfile
import os
import signal

class CodeSandbox:
    """
    Safely executes LLM-generated Python code.
    If the code doesn't match exactly, returns None.
    """
    
    TIMEOUT_SECONDS = 5
    
    def execute(self, code: str, orders: list, bank_credit_amount: float) -> dict:
        # Create a temporary Python file
        with tempfile.NamedTemporaryFile(mode='w', suffix='.py', delete=False) as f:
            # Add the generated function + test invocation
            test_code = f"""
{code}

# Test invocation
result = find_match({orders}, {bank_credit_amount})
print(result)
"""
            f.write(test_code)
            temp_path = f.name
        
        try:
            # Execute with timeout
            result = subprocess.run(
                ['python', temp_path],
                capture_output=True,
                text=True,
                timeout=self.TIMEOUT_SECONDS
            )
            
            if result.returncode == 0 and result.stdout.strip() != "None":
                import json
                return json.loads(result.stdout.strip())
            else:
                return None
        
        except subprocess.TimeoutExpired:
            return {"error": "COMBINATORIAL_TIMEOUT"}
        
        finally:
            os.unlink(temp_path)
```

### 5.5 Stage 4: Honest Exception Orchestrator (`src/stage4_exception.py`)

**Logic:** For all unresolved records, generate a forensic dossier documenting every step taken.

```python
class Stage4ExceptionOrchestrator:
    def run(self, unresolved_records, audit_trail) -> Stage4Result:
        exceptions = []
        processing_errors = []
        
        for record in unresolved_records:
            try:
                dossier = self._generate_forensic_dossier(record, audit_trail)
                
                # Generate dispute payload
                dispute_payload = self._generate_dispute_payload(record, dossier)
                
                # Update ledger status
                self._update_ledger_status(record.order_id, "ESCALATED")
                
                # Push webhook (simulate)
                self._push_webhook(dispute_payload)
                
                exceptions.append(ExceptionRecord(
                    record=record,
                    dossier=dossier,
                    dispute_payload=dispute_payload,
                    status="ESCALATED"
                ))
            
            except Exception as e:
                processing_errors.append(ProcessingError(
                    record_id=record.order_id,
                    error=str(e),
                    stage="stage4_exception_orchestrator"
                ))
        
        return Stage4Result(exceptions, processing_errors)
    
    def _generate_forensic_dossier(self, record, audit_trail) -> dict:
        return {
            "record_id": record.order_id,
            "timestamp": datetime.now().isoformat(),

                {"step": "Stage 2: AI Semantic Normalization", "result": "FAILED", "reason": "Bank narration could not be matched to any internal order"},
                {"step": "Stage 3: Multi-Leg Graph Resolution", "result": "FAILED", "reason": "No combination of orders + fees equals the bank credit amount"},
```

### 5.6 Fee Calculator (`src/fee_calculator.py`)

```python
class FeeCalculator:
    """
    Deterministic fee calculation engine.
    This is the source of truth for all fee computations.
    """
    
    FEE_MATRIX = {
        "upi": 0.00,
        "netbanking": 0.01,
        "credit_card": 0.02,
        "debit_card": 0.015,
        "wallet": 0.02,
    }
    
    TDS_RATE = 0.01  # 1% TDS
    
    def calculate_mdr(self, amount: float, payment_method: str) -> float:
        rate = self.FEE_MATRIX.get(payment_method, 0.02)  # Default to 2%
        return round(amount * rate, 2)
    
    def calculate_tds(self, amount: float) -> float:
        return round(amount * self.TDS_RATE, 2)
    
    def calculate_net_settlement(self, order) -> float:
        mdr = self.calculate_mdr(order.amount, order.payment_method)
        refund = order.refund_amount or 0.00
        net = order.amount - mdr - refund
        
        if order.route_split:
            # For Route splits, platform fee is already included in route_split
            net = order.route_split.vendor_amount - refund
        
        return round(net, 2)
```

### 5.7 Audit Trail (`src/audit_trail.py`)

```python
class AuditTrail:
    """
    Append-only audit log. Every decision is recorded.
    """
    
    def __init__(self):
        self.entries = []
        self.current_id = 0
    
    def log(self, event: str, data: dict = None):
        self.current_id += 1
        self.entries.append({
            "id": self.current_id,
            "timestamp": datetime.now().isoformat(),
            "event": event,
            "data": data or {},
        })
    
    def log_match(self, record_id: str, match_type: str, confidence: float):
        self.log("MATCH_FOUND", {
            "record_id": record_id,
            "match_type": match_type,
            "confidence": confidence,
        })
    
    def log_exception(self, record_id: str, reason: str):
        self.log("EXCEPTION_FLAGGED", {
            "record_id": record_id,
            "reason": reason,
        })
    
    def to_json(self) -> str:
        return json.dumps(self.entries, indent=2)
    
    def to_dataframe(self):
        import polars as pl
        return pl.DataFrame(self.entries)
```
